# ZZZ Academy — Frontend

Frontend del TFG **ZZZ Academy**, una aplicación web de referencia para el videojuego *Zenless Zone Zero*. Desarrollado con **Angular 19**, permite explorar el catálogo de personajes, equipamiento y Bangboos, gestionar un roster personal y consultar una Tier List.

---

## Cómo ejecutarlo en local

### Requisitos previos
- **Node.js** (versión LTS, recomendado Node 22+)
- El **backend** ejecutándose en `http://localhost:8080`

### Pasos

**1. Instalar dependencias**

Desde esta carpeta (`frontend/`):

```bash
npm install
```

**2. Arrancar la aplicación**

```bash
npm start
```

La aplicación estará disponible en `http://localhost:4200`.

> Es necesario que el backend y la base de datos estén corriendo antes de abrir la aplicación. Consulta el `README.md` del backend para arrancarlo.
